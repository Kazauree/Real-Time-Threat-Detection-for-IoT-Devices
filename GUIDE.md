## 1. 🔰 Beginner's Introduction: How the Software Works

### What is the problem?
Internet of Things (IoT) devices—such as smart security cameras, environmental sensors, smart thermostats, smart locks, and industrial gateways—are connected to home and enterprise networks. Because these devices often have limited processing power and simple security settings, cyberattackers target them to perform malicious attacks, such as **Denial of Service (DoS)** floods, **Port Scanning**, **Brute Force password cracking**, and **Botnet infection**.

### How does this software solve it?
This software acts as an **Intelligent Cyber Security Operations Center (SOC)** for IoT networks:

1. **Traffic Collection**: Network flows (packet numbers, flow duration, byte sizes, port numbers) generated by IoT devices are continuously monitored.
2. **AI Analysis (Random Forest Machine Learning)**: Instead of relying on static firewall rules, the trained **Random Forest Machine Learning Classifier** analyzes flow parameters and determines whether the activity is **Legitimate (Normal)** or an active **Cyberattack** (DoS, Port Scan, Brute Force, Botnet, or Suspicious).
3. **Instant Real-Time Alerts (WebSockets)**: When an attack is detected, the server instantly sends a real-time notification to the administrator's web browser without requiring a page refresh.
4. **Visual Security Dashboard**: The administrator logs into a modern dark-themed web dashboard to inspect device risk scores, view attack trends, examine raw network telemetry, and read AI-suggested security response playbooks.

## 3. 🚀 Step-by-Step Execution Guide

### Option A: Automatic Launch (Recommended)

The project includes an automated master launcher script (`start_system.py`) that sets up the environment, trains the machine learning model, seeds the database, and launches all background services.

```bash
# 1. Open your terminal and navigate to the project directory
cd /home/kazauree/Desktop/Samuel

# 2. Run the master launcher script
python3 start_system.py
```

`start_system.py` will execute the following steps automatically:
- Creates a Python virtual environment (`venv`).
- Installs Python dependencies (`Flask`, `Scikit-Learn`, `Pandas`, `NumPy`, `SQLAlchemy`, etc.).
- Generates the synthetic IoT dataset (`ml/dataset/iot_network_traffic.csv`).
- Trains the Random Forest Machine Learning Model (`ml/saved_models/random_forest.pkl`).
- Seeds default administrator accounts and sample IoT devices.
- Starts the **Backend API Server** on `http://localhost:5000`.
- Starts the **React Web Dashboard** on `http://localhost:5173`.
- Starts the **IoT Traffic Simulator** generating real-time flow events.

## 7. 🗄️ Database Design & Schema

The relational database is built using **SQLAlchemy ORM** and stored in `database/iot_threats.db`.

### Core Tables Summary

1. `users`: Stores system administrators and security analysts (`id`, `name`, `email`, `password_hash`, `role`).
2. `devices`: Monitored IoT hardware inventory (`id`, `device_name`, `device_type`, `ip_address`, `mac_address`, `manufacturer`, `status`, `risk_level`, `last_seen`).
3. `traffic_records`: Captured network flow telemetry (`id`, `device_id`, `source_ip`, `destination_ip`, `destination_port`, `protocol`, `packet_count`, `byte_count`, `flow_duration`, `features_json`, `source_type`).
4. `predictions`: Machine learning inference outputs (`id`, `traffic_id`, `prediction`, `confidence`, `severity`, `model_version`).
5. `threats`: Identified security attack incidents (`id`, `device_id`, `prediction_id`, `threat_type`, `severity`, `description`, `status`).
6. `alerts`: System notification triggers (`id`, `threat_id`, `title`, `message`, `severity`, `is_read`).
7. `model_versions`: Model metadata and training history (`id`, `version`, `accuracy`, `precision`, `recall`, `f1_score`).
8. `security_logs`: Audit trail of user logins and security actions (`id`, `user_id`, `action`, `ip_address`, `description`).

## 8. 🧠 Machine Learning Engine & Random Forest Model

### Algorithm: Random Forest Classifier
A **Random Forest** is an ensemble machine learning algorithm that constructs a multitude of decision trees during training and outputs the class that is the mode of the classes of the individual trees. This prevents overfitting and provides high classification accuracy.

### Traffic Features Extracted
1. `flow_duration`: Duration of the network flow in milliseconds.
2. `packet_count`: Total packets sent during the session.
3. `byte_count`: Total payload bytes transferred.
4. `pkt_len_mean`: Average packet length in bytes.
5. `pkt_len_std`: Standard deviation of packet sizes.
6. `flow_pkts_per_sec`: Packet transmission rate (pkts/sec).
7. `flow_bytes_per_sec`: Data transmission rate (bytes/sec).
8. `port_entropy`: Statistical randomness metric of destination ports.
9. `dest_port`: Destination port number (e.g. 22 for SSH, 80 for HTTP).
10. `protocol`: Network layer protocol (`TCP`, `UDP`, `ICMP`).
